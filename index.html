Écrire en Markdown

Le Markdown permet de mettre en forme un texte avec quelques symboles, directement dans un fichier texte. On l’utilise pour les fichiers README, les notes, la documentation.

Ce guide montre les éléments les plus courants. Dans chaque exemple, la colonne de gauche contient ce qu’on écrit, celle de droite ce qu’on obtient.

La mise en forme, pas à pas

Les titres

Utilise le caractère #. Plus il y en a, plus le titre est petit.

À écrire 
# Titre principal
## Sous-titre
### Petit titre
Résultat

Titre principal

Sous-titre

Petit titre

À retenir : mets un espace après les # et garde les titres dans un ordre logique.

Les paragraphes

Une ligne vide sépare deux paragraphes.

À écrire 
Voici un premier paragraphe.

Voici un deuxième paragraphe.
Résultat

Voici un premier paragraphe.

Voici un deuxième paragraphe.

Gras, italique et barré

Entoure le texte d’astérisques (ou de tirets bas). Le texte barré s’écrit avec deux tildes.

À écrire 
**Texte en gras**
*Texte en italique*
~~Texte barré~~
Résultat

Texte en gras

Texte en italique

Texte barré

Les listes

Commence la ligne par - ou * pour une liste à puces, par un nombre suivi d’un point pour une liste numérotée. Deux espaces de plus décalent un élément d’un niveau.

À écrire 
- Première idée
- Deuxième idée
  - Détail

1. Première étape
2. Deuxième étape
Résultat
  • Première idée
  • Deuxième idée
    • Détail
  1. Première étape
  2. Deuxième étape

Les liens et les images

Un lien utilise des crochets pour le texte et des parenthèses pour l’adresse. Une image s’écrit pareil, avec un point d’exclamation devant.

À écrire 
[Visiter le site](https://exemple.fr)

![Description de l'image](images/photo.png)
Résultat

Visiter le site

[ Description de l’image ]

À retenir : le texte entre crochets d’une image sert de description si l’image ne s’affiche pas.

Citations et séparateurs

Le symbole > crée une citation. Trois tirets forment une ligne de séparation.

À écrire 
> Une citation ou une remarque importante.

---
Résultat
Une citation ou une remarque importante.

Les tableaux

Les barres verticales séparent les colonnes. La ligne de tirets sépare l’en-tête du contenu.

À écrire 
| Langage | Usage     |
| ------- | --------- |
| HTML    | Structure |
| CSS     | Apparence |
Résultat
LangageUsage
HTMLStructure
CSSApparence

Afficher du code

Pour un mot ou une commande dans une phrase, entoure-le d’accents graves. Pour plusieurs lignes, ouvre et ferme le bloc avec trois accents graves.

Dans une phrase

À écrire 
Lance `npm install` pour
installer les dépendances.
Résultat

Lance npm install pour installer les dépendances.

Dans un bloc

Écris le nom du langage juste après les trois premiers accents graves : certains aperçus colorent alors le code.

À écrire 
```html
<h1>Bonjour !</h1>
<p>Mon premier exemple.</p>
```
Résultat 
<h1>Bonjour !</h1>
<p>Mon premier exemple.</p>

Deux détails en plus

Les listes de tâches

Écris - [ ] pour une tâche à faire et - [x] pour une tâche terminée.

À écrire 
- [ ] Écrire le titre
- [x] Créer le fichier
Résultat
  • Écrire le titre
  • Créer le fichier

Les lignes vides

Laisse une ligne vide entre deux éléments (titre, liste, tableau, bloc de code). C’est plus lisible, et certains aperçus n’affichent pas correctement les éléments collés les uns aux autres.

L’aperçu dans VS Code

L’aperçu affiche ton fichier comme un document mis en forme, sans modifier le texte Markdown que tu as écrit.

  1. Ouvre un fichier qui se termine par .md.
  2. Appuie sur Ctrl + Maj + V
  3. Pour afficher l’aperçu à côté du texte : Ctrl + K, puis V.

Tu peux aussi faire un clic droit sur l’onglet du fichier et choisir « Ouvrir l’aperçu ».
