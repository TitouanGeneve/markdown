# Markdown — le guide pratique

Une petite page web pour apprendre les bases du Markdown : titres, listes, liens, tableaux, code, et aperçu dans VS Code.

## Utilisation

Ouvre `index.html` dans ton navigateur. Aucune installation n’est nécessaire.

## Contenu

- `index.html` : le guide
- `css/style.css` : la mise en forme
